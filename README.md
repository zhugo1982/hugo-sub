# hugo-sub

### 一键部署命令（Debian 12 VPS）
```bash
curl -sSL https://raw.githubusercontent.com/zhugo1982/hugo-sub/refs/heads/main/sub.sh -o /usr/local/bin/hugo-sub && chmod +x /usr/local/bin/hugo-sub && hugo-sub
```
或者
```
bash <(curl -Ls https://raw.githubusercontent.com/zhugo1982/hugo-sub/main/sub.sh)
```
快捷方式取节点：```hugo-sub```
